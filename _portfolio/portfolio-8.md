## Overview

A 2D platformer built in Godot for **CS 415 (Game Development)** as a group project. The core mechanic is variable gravity: each planet pulls the player differently, so traversal depends on reading and exploiting the gravitational field of whichever body the player is near rather than on fixed jump arcs.

## Features

- **Variable gravity traversal:** Movement and jump behavior change per planetary body, making gravity the central puzzle element rather than a constant
- **Multi-level design:** Several levels with distinct planetary layouts
- **Scene management and game state tracking:** Level transitions and persistent game state handled through Godot's scene system
- **Background music system:** Audio playback managed across scene changes

## Tech Stack

GDScript, Godot
